# Contributing to shielded-sdk

Welcome! We're thrilled that you want to contribute to the TypeScript SDK of the Shielded Protocol.

## Contributor Tracks

### 1. TypeScript SDK (pnpm monorepo)
- Setup: Install `pnpm`.
- Build: `pnpm install && pnpm build`
- Test: `pnpm test`
- Good issues: Look for `layer:sdk` labels.

### 2. Smart Contracts (Rust)
- Head over to `shielded-contracts`.
- Good issues: Look for `layer:contracts`.

### 3. ZK Circuits (Circom)
- Head over to `shielded-circuits`.
- Good issues: Look for `layer:circuits`.

## Your First PR

1. Fork the repo.
2. Create a branch: `git checkout -b feat/my-sdk-change`.
3. Make your changes and add tests.
4. Ensure all packages build correctly.
5. Submit a PR!

## PR Checklist

- [ ] Tests pass locally
- [ ] Docs updated (if behavior changed)
- [ ] All packages build correctly
- [ ] Issue linked

## Code of Conduct

We follow the Contributor Covenant. Be kind and professional.
